# 01 项目概述

## 1. 项目定位

Saiye 是一个以"稍后阅读 / 书签收藏"为核心、面向 AI 增强的个人信息管理系统:

- **收藏一切**:链接、文本笔记、图片、PDF、视频
- **AI 增强**:LLM 自动打标签、自动摘要、图片 OCR、语音转写、语义向量索引
- **自动处理**:无头 Chrome 抓取网页(标题/描述/截图/整页归档)、yt-dlp 下载视频
- **快速找回**:全文检索 + 语义向量搜索 + 混合搜索(RRF 融合)
- **多端覆盖**:Web、移动端(iOS/Android)、浏览器扩展、CLI、MCP、桌面端
- **自托管优先**:Docker 单容器(s6-overlay)即可完整运行

项目基于开源项目 Karakeep(原名 Hoarder)二次开发并独立再品牌,许可证为 **GNU AGPL-3.0**。

## 2. 核心功能特性

| 功能域 | 说明 |
|---|---|
| 书签管理 | 链接/文本/资产三类书签、列表(手动/智能)、标签、收藏、归档、高亮、阅读进度、批量操作 |
| 网页抓取 | 无头 Chrome 渲染、metascraper 元数据、截图、PDF、全页归档(monolith)、视频下载(yt-dlp)、广告拦截、Cookie 弹窗自动处理 |
| AI 能力 | 自动打标签(支持相似书签上下文)、自动摘要、图片 OCR(Tesseract/LLM 视觉)、PDF 文本提取、音频转写、AI 聊天(实验性)、概念页(AI 编译知识页) |
| 搜索 | Meilisearch 全文索引 + 向量存储,支持 fts / semantic / hybrid 三种模式与结构化查询语法 |
| 自动化 | 规则引擎(事件→条件→动作)、Webhook、RSS 订阅自动收藏、Markdown 镜像导出(Obsidian 风格) |
| 协作与分享 | 协作列表(viewer/editor 角色)、公开列表、RSS token 分享、Agent 资产分享 |
| 数据安全 | 用户备份(zip 归档)、两阶段导入(11 种来源)、JSON/Netscape 导出 |
| 平台 | 多语言(32 种)、暗色模式、SSO(OIDC/微信扫码)、Stripe 订阅配额 |

## 3. 技术栈

| 维度 | 选型 |
|---|---|
| Monorepo | **Turborepo** + **pnpm**(workspace + hoisted,见 [pnpm-workspace.yaml](../pnpm-workspace.yaml)) |
| 前端 | **Next.js 16**(App Router)、React 19、TypeScript、Tailwind CSS、shadcn/ui |
| 移动端 | **Expo 56**(React Native 0.85)+ NativeWind |
| 落地页 | **Astro 6** |
| 桌面端 | **Tauri 2**(进程监督者管理 meilisearch/web/workers 子进程) |
| 后端框架 | **Hono**(挂载于 Next.js catch-all API 路由) |
| RPC | **tRPC v11**(superjson transformer,端到端类型安全) |
| ORM | **Drizzle ORM**(SQLite 方言,better-sqlite3 驱动) |
| 数据库 | **SQLite**(单文件,可选 WAL 模式) |
| 搜索/向量 | **Meilisearch**(全文检索 + 向量存储) |
| AI 推理 | OpenAI 兼容 API / **Ollama**(本地模型) |
| 任务队列 | 自研队列抽象,可插拔实现(LiteQueue 单机 / Restate 分布式) |
| 部署 | Docker(s6-overlay 单容器 / 双容器 Compose)、Kubernetes(Kustomize) |
| 工具链 | **Oxfmt**(格式化)、**oxlint**(检查)、**Vitest**(测试)、Sherif(monorepo 规则) |
| 可观测性 | OpenTelemetry(tracing + event logs)、Prometheus 指标 |

> **数据库说明**:仓库当前实现为 **SQLite 专用** —— [packages/db/drizzle.config.ts](../packages/db/drizzle.config.ts) 固定 `dialect: "sqlite"`,[packages/db/index.ts](../packages/db/index.ts) 导出 better-sqlite3 的 `SqliteError`,schema 全部使用 `drizzle-orm/sqlite-core`。

> **认证说明**:Web 侧使用 **NextAuth (next-auth v4)** + DrizzleAdapter(见 [apps/web/server/auth.ts](../apps/web/server/auth.ts)),API 侧支持 API Key(`ak2_` 前缀,SHA-256 + timingSafeEqual)。

## 4. 仓库基本信息

- 根包名:`@saiye/root`([package.json](../package.json)),包管理器 `pnpm@11.2.1`,Node 版本见 [.nvmrc](../.nvmrc)
- 工作区:`apps/*`、`packages/*`、`tooling/*`、`tools/*`、`docs`
- 补丁机制:`patches/` 目录通过 pnpm `patchedDependencies` 修复上游依赖(react-native、drawnix、playwright-extra 等)
- CI:GitHub Actions([.github/workflows/](../.github/workflows/)),覆盖 web/extension/cli/sdk/mcp/android/ios/docker
