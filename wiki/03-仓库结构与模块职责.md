# 03 仓库结构与模块职责

工作区由 [pnpm-workspace.yaml](../pnpm-workspace.yaml) 定义:`packages/*`、`apps/*`、`tooling/*`、`tools/*`、`docs`,nodeLinker 为 hoisted。

## 1. 顶层目录速览

```
/workspace
├── apps/                 # 应用层(可独立部署/发布的产物)
│   ├── web/              # 主应用:Next.js(前端 + API 网关宿主)
│   ├── workers/          # 后台任务进程(15 个 worker + 指标服务)
│   ├── mobile/           # Expo 移动端(iOS/Android)
│   ├── browser-extension/# Chrome/Firefox 扩展
│   ├── cli/              # 命令行客户端(pnpm 包 @saiye/cli)
│   ├── mcp/              # Model Context Protocol 服务器
│   ├── landing/          # Astro 官网落地页
│   └── desktop/          # Tauri 2 桌面壳
├── packages/             # 共享包(库)
│   ├── trpc/             # ★ 业务逻辑核心:tRPC 路由 + 领域模型
│   ├── api/              # ★ Hono 应用与 REST /v1 路由
│   ├── db/               # ★ Drizzle schema + 迁移(101 个)
│   ├── shared/           # ★ 全栈共享:配置/类型/抽象接口/推理客户端
│   ├── shared-server/    # ★ 服务端共享:队列定义/插件加载/事件日志/配额
│   ├── shared-react/     # 跨端 React:hooks + Provider + 高亮组件
│   ├── plugins/          # 可插拔实现:meilisearch×2 / liteque / restate / 限流×2
│   ├── open-api/         # OpenAPI 规范生成器
│   ├── sdk/              # 面向外部的类型化 HTTP SDK
│   ├── e2e_tests/        # 端到端测试(真实容器栈)
│   └── benchmarks/       # 性能基准(tinybench)
├── tooling/              # 共享工程配置(tsconfig / tailwind / oxlint / prettier / github action)
├── tools/                # 独立工具(compare-models 盲测 / seed-snapshot 种子数据)
├── docs/                 # Docusaurus 文档站 + 设计文档
├── docker/               # Dockerfile(多阶段) + docker-compose 三套
├── kubernetes/           # Kustomize 部署清单
├── patches/              # pnpm 补丁(react-native、drawnix 等 8 个)
├── charts/               # Helm/图表占位
└── snapshots/            # 种子数据快照
```

## 2. 应用(apps/)

| 应用 | 包名 | 职责 | 详见 |
|---|---|---|---|
| `apps/web` | `@saiye/web` | **主应用**:Next.js 16,承载全部 UI、挂载 Hono API(catch-all)、NextAuth 认证、RSC 端 tRPC 服务端调用 | [08-Web前端](./08-Web前端.md) |
| `apps/workers` | `@saiye/workers` | **后台任务进程**:单进程多 worker(15 个)+ cron 调度器 ×3 + DB 轮询 worker ×1 + 指标 HTTP 服务 | [07-后台任务系统](./07-后台任务系统.md) |
| `apps/mobile` | `@saiye/mobile` | Expo 56 + React Native 0.85 移动端,复用 shared-react hooks,支持离线阅读、系统分享接收、语音笔记 | [10-客户端应用](./10-客户端应用.md) |
| `apps/browser-extension` | — | Manifest V3 扩展,popup SPA + service worker,SingleFile 整页捕获,tRPC 直连 | 同上 |
| `apps/cli` | `@saiye/cli` | 命令行(bin 名 `saiye`),tRPC 为主 + REST 为辅,含 admin/migrate/wipe/dump 命令 | 同上 |
| `apps/mcp` | `@saiye/mcp` | MCP 服务器(stdio),向 LLM 暴露 29 个工具,走 SDK REST | 同上 |
| `apps/landing` | — | Astro 6 官网(首页/定价/隐私/条款) | 同上 |
| `apps/desktop` | — | Tauri 2 桌面壳:托盘 + 全局快捷键 + Node 进程监督者(meilisearch/web/workers) | 同上 |

| 包 | 职责 | 详见 |
|---|---|---|

| `packages/api` | Hono 应用与 REST `/v1` 路由(16 个路由文件)、中间件(auth/scope/rateLimit/trpcAdapter)、上传/资产/RSS 工具;**Hono 外壳 + tRPC 内核** | [05-API网关层](./05-API网关层.md) |
| `packages/db` | Drizzle SQLite schema(45+ 表)、101 个迁移、异步事务补丁、OTel 埋点 | [04-数据库设计](./04-数据库设计.md) |
| `packages/shared` | 全栈共享:serverConfig/clientConfig(Zod 解析 150+ 环境变量)、Queue/Search/VectorStore/RateLimit 四大抽象接口、PluginManager、InferenceClientFactory、AssetStore(本地/S3)、签名 token、搜索语法解析器、21 个类型文件、13 个工具、导入导出 | [09-共享基础库](./09-共享基础库.md) |

| `packages/plugins` | 6 个可插拔后端:queue-liteque(默认)/ queue-restate(分布式)/ search-meilisearch / vectorstore-meilisearch / ratelimit-memory / ratelimit-redis | 同上 |
| `packages/open-api` | 用 @asteasolutions/zod-to-openapi 生成 OpenAPI 3.0 规范(CI 漂移检查) | [05-API网关层](./05-API网关层.md) |
| `packages/sdk` | 基于 openapi-fetch 的类型化 REST 客户端(CLI/MCP/工具复用) | 同上 |
| `packages/e2e_tests` | 对完整容器栈(web/workers/nginx/S3 mock/AI mock)的端到端验收 | [12-开发与运行指南](./12-开发与运行指南.md) |
| `packages/benchmarks` | tinybench API 基准(create/list/search),docker-compose 起类生产栈 | 同上 |

## 5. 文档与部署

- `docs/`:Docusaurus 文档站(8 个分类 + OpenAPI 自动生成的 API 参考 + 6 个版本快照),仓库内设计文档:`ARCHITECTURE.md`、`CANVAS_CHAT_FEATURE.md`、`DESKTOP_PHASE0_DESIGN.md`、`WIDGET_SANDBOX_DESIGN.md`、`WIDGET_WRITE_API_DESIGN.md`、`PI_AGENT_ARCHITECTURE_DESIGN.md`、`MEMORY_SPACE_ROADMAP.md` 等。
- `docker/`:多阶段 Dockerfile(5 个 target:aio/web/workers/cli/mcp)+ 三套 compose(生产/构建/开发)。
- `kubernetes/`:Kustomize 清单(namespace/secret/configmap/web/chrome/meilisearch/pvc/ingress)。

## 6. 构建编排(turbo.json)

[turbo.json](../turbo.json) 定义任务图:`build` 依赖 `^build`(拓扑序),输出 `.next/**`、`dist/**` 等;`dev` 为 persistent 不缓存;`typecheck/lint` 依赖 `^topo`;全局依赖 `**/.env`。根 [package.json](../package.json) 的脚本(`build/dev/lint/format/test/typecheck/preflight` 等)全部经 turbo 分发到各 workspace。
